# Arc VCC 2026 参考资料库

本库只服务于“跨细胞系共享 GRN-ODE 预测 gene knockdown 响应”的项目设计。科学入口是 [技术路线与项目设计](../技术路线与项目设计.md)，方法调研、归档和复用的执行入口是 [参考资料与方法复用治理规则](rules.md)。

## 内容

- [idea库](idea库)：将原有通用想法收敛为可检验的 Arc VCC 建模原则；其中“跨环境重叠与因果校正”定义模型训练前的数据证据前端；
- [文献](文献)：只保留与主路线直接相关的论文、方法卡和官方入口；
- [templates](templates)：阶段方法调研、复用决策和方法卡的规范模板；
- `reuse_registry.yaml`：由 R00 实际调研后生成的机器可读复用索引；文件未生成前不得声称项目已有完整 registry。

## 使用规则

- 任何阶段的方法规划或实现前，完整阅读 [`rules.md`](rules.md) 并执行该阶段 `T00`；R00、旧方法卡和静态必读清单不能替代现场调研；
- 新论文/方法一旦进入 shortlist、影响设计或准备复用，先建立方法卡、加入文献索引并核验一手来源、版本和许可；
- 外部公开多细胞系 perturbation 数据是 P0 训练资产；必须先核对许可、细胞系、扰动类型、时间、协议和 matched NTC；
- 不对所有细胞系做无差别 batch integration。先以 matched NTC 构造条件效应，再按初态共同支持域进行分层/加权；初态本身是要保留的生物学条件；
- 目标验证/测试细胞系的扰动后响应一律视为隐藏标签，除非官方明确发布；
- 现成 GRN、知识图、foundation model、预测器、solver 和评测工具应优先按其成熟 module/interface 复用；它们各自的科学边界仍以方法卡和 stage decision 为准，不能自动替代项目核心假设；
- 文献库不保存第三方代码、数据快照、结果缓存或嵌套版本库。实现开始时从方法卡中的官方入口获取，并单独核验许可证。
