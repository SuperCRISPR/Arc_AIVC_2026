# Linear Baselines

## 项目位置

该基准文献说明复杂深度模型并不天然优于简单线性方法。它为本项目设置不可绕过的强基线与复杂度门控。

## 必须保留的对照

```text
no-change -> matched/source mean delta -> ridge/elastic net
-> reduced-rank program linear -> same-capacity one-step -> shared GRN-ODE
```

只有共享 GRN-ODE 在严格 LOCO/LOPO 中稳定优于这些对照，才授权保留其额外复杂度。
