# 因果重叠校正：方法卡

## 在本项目中的定位

这是 GRN-ODE 之前的证据校正层，不是第二个主模型。它以 matched NTC 条件差分为锚，再使用共同支持域、协变量平衡和不确定度标记，使跨细胞系共享机制的训练证据更可比。完整数据流见[跨环境重叠与因果校正](../../idea库/06_跨环境重叠与因果校正.md)。

## 推荐优先级

| 优先级 | 方法 | 直接用途 | 不应误用为 |
| --- | --- | --- | --- |
| P0 | matched NTC assignment effect、condition uncertainty、共同支持域审计 | 生成 E1、避免单细胞伪重复、排除没有可比状态支持的记录 | 单细胞前后配对、每单位实际敲低效应或完整 batch 去除 |
| P1 | 分层随机效应 / 低维 meta-regression | 汇总共享项、状态依赖、技术异质性、预测区间与 leave-one-environment-out | 用几十万 cells 替代少量独立环境；恢复直接因果边 |
| P2 | 熵平衡/核平衡/稳定平衡权重 | 独立环境足够时让同一 KD 的证据面向预定义 E3 目标总体 | 对每个细胞估计“接受某 KD 的概率”或补出 positivity |
| P2 | 双重稳健、DML、CATE | 可交叉拟合时给低维 E3/候选边摘要提供稳健估计 | 处理不可观测的 KD x batch 偏差 |
| P2 | DID/三重差分 | 有跨批次/协议重复时量化残余 interaction | 在只有单个终点、无重复时声称平行趋势 |
| P3 | guide-IV | 多 guide 且识别条件满足时校准 E2/soft-intervention 强度 | 默认跨环境校正、target-level E1 或直接 gene edge |
| P3 | ICP/JCI、BackShift 类 | 已校正数据上的跨环境候选边/程序筛选 | 直接取代预测模型、用不显著结果证明不变或保证非线性因果发现 |

任何 P1-P3 方法之前先画出 `cell line/state -- batch/protocol -- KD` 的交叉重复图，并冻结 E1-E4 中本次实际估计的对象。图不连通或 `cell line` 与 `batch` 一一对应时，状态与批次完全混杂；该数据不能作为“共享机制”识别证据。

后处理不是对表达矩阵做无约束减法，而是对候选边/程序效应做带环境项的分层汇总、方差膨胀和敏感性门控；不稳定效应不进入共享 GRN。

## 论文与可复用思想

| 论文 | 可复用思想 | 对本项目的边界 |
| --- | --- | --- |
| [Rosenbaum & Rubin, 1983, Biometrika](https://doi.org/10.1093/biomet/70.1.41) | 倾向评分的平衡性质与 common support | 处理的是已观测协变量；这里应对 condition-level KD 覆盖做广义/密度比加权 |
| [Imai & Ratkovic, 2014, JRSSB](https://doi.org/10.1111/rssb.12027) | Covariate Balancing Propensity Score：直接以协变量平衡为拟合目标 | 比追求高分类准确率更符合需求；仍须检查 positivity |
| [Hainmueller, 2012, Political Analysis](https://doi.org/10.1093/pan/mpr025) | Entropy balancing 的精确矩匹配与稳定权重 | 适合少量预定义 NTC program 与元数据；高维时需正则与有效样本量审计 |
| [Higgins, Thompson & Spiegelhalter, 2009, JRSSA](https://doi.org/10.1111/j.1467-985X.2008.00552.x) | 随机效应汇总、异质性解释与预测区间 | 默认汇总应同时表达均值和未来环境效应范围；少环境下不确定度不能被忽略 |
| [Viechtbauer, 2010, JSS](https://doi.org/10.18637/jss.v036.i03) | mixed-effects meta-regression、moderator 与诊断的成熟实现参考 | R00/T00 仍需核验当前实现、许可和多层/多变量接口；moderator 数受独立环境数约束 |
| [Chernozhukov et al., 2018, Econometrics Journal](https://doi.org/10.1111/ectj.12097) | cross-fitting 的 double/debiased ML | 用于低维 effect summary/边分数及置信度；不是原始表达矩阵的万能“去混杂” |
| [Nie & Wager, 2021, Biometrika](https://doi.org/10.1093/biomet/asaa076) | R-learner 式异质处理效应学习 | `S` 是要条件化的效应修饰变量；可用于多任务 program 效应的二阶段参考 |
| [Peters, Buhlmann & Meinshausen, 2016, JRSSB](https://doi.org/10.1111/rssb.12167) | Invariant Causal Prediction：跨环境不变性约束 | 用来筛查共享候选调控关系；其机制不变假设必须接受 LOCO 检验 |
| [Mooij et al., 2020, JMLR](https://jmlr.org/papers/v21/17-678.html) | Joint Causal Inference：把环境/干预作为 context variables 建模 | 很适合组织多来源数据的因果图假设；不自动解决缺失元数据或 batch interaction |
| [Rothenhausler et al., 2015, NeurIPS](https://arxiv.org/abs/1506.02494) | BackShift：未知 shift interventions 下的循环图学习 | 仅作为低维线性化 program 图的强假设筛选；需检验隐藏混杂在环境间稳定 |
| [Gagnon-Bartsch & Speed, 2012, Biostatistics](https://doi.org/10.1093/biostatistics/kxr034) | 用技术控制估计 unwanted variation | 仅可在 NTC/有效技术控制下作技术校准；绝不将细胞系初态当 unwanted variation 删除 |

## 暂不作为主线的方向

- **Proximal causal learning / negative controls**：理论上能以有效代理处理未观测混杂，但需要独立的负对照暴露和结局满足 confounding-bridge 条件。NTC treatment 不是自动合格的双代理；先审计实验设计，再决定是否进入 P3。
- **Guide 工具变量**：只在多 guide、first stage、排除限制、单调性、脱靶和存活选择条件可辩护时估计 E2 或校准 `rho`。方法/实现进入 shortlist 前必须另建方法卡；E1 和比赛 E4 不依赖它才能定义。
- **DID 与 synthetic control**：课程中的框架有价值，但本任务常见的是终点横截面条件分布，缺少多期 pre-treatment outcome。只有重复批次/时间或明确参考条件时才评估。
- **E-value / regression robustness value**：两者面向不同效应尺度和模型。默认均不输出；只有 estimand、处理定义、尺度和偏差模型匹配时，才在 T00 中注册具体敏感性方法。
- **通用批次整合模型**：用于可视化的 batch mixing 指标不能证明因果可比性，且可能擦除真正的 KD response；不生成主训练标签。

## 课件映射

临时参考文件中的 `3.2_observational_matching`、`3.3_observational_PS`、`3.4_observational_weighting`、`3.5_Doubly Robust Estimation`、`3.6_Non-Binary Treatment` 和 `8_DID` 对应本卡的 P0--P2。其共同前提是：平衡/加权解决的是已观测协变量；overlap 可诊断，而未观测混杂需要设计、负对照或敏感性分析，不能由更复杂的预测模型自动消除。
