# 基线、验证与复杂度门控

## 不可跳过的基线

| 层级 | 模型 | 检验目的 |
| --- | --- | --- |
| B0 | no-change | 是否恢复了任何扰动信号 |
| B1 | source/匹配 context 平均 delta | 是否只输出总体均值 |
| B2 | ridge / elastic net | 是否已可由线性作用解释 |
| B2H | hierarchical conditional-effect model | NTC state、共享 target effect 与 study/protocol/lineage 异质性是否已足够 |
| B3 | program-level reduced-rank linear | 低维结构是否足够 |
| B4 | 同容量 one-step | ODE 的连续结构是否有独立增益 |
| B5 | 共享 nonlinear GRN-ODE | 项目主模型 |

## 主要验证

主验证是 leave-one-cell-line-out；辅助验证为 leave-one-perturbation-out 和双留出。数据连接允许时，增加同 study 内 LOCO、同 cell model 跨 study、leave-one-study-out 和 leave-one-lineage-out，用于拆分生物背景与协议泛化。随机单细胞切分只能检查实现，不能证明 zero-shot 泛化。

按 cell line 与 perturbation 分层报告 expression/delta 误差、相关性、DEG 方向、分布距离与方差校准，并用 bootstrap 或重复运行检查稳定性。对知识图增加无图/真图/随机图消融；对状态增加 state swap/context permutation；对 adapter 比较关闭、受限和自由版本。

## 升级规则

只有复杂模型在严格 OOD 切分中稳定超过强线性基线，且提升不依赖隐藏标签、随机切分或更大的不可解释容量时，才将其保留。否则回退到更简单、可复现的模型。
