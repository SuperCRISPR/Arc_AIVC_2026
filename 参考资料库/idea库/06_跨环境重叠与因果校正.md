# 跨环境重叠与因果校正

## 结论先行

本项目不追求把所有细胞系变成同一个“去状态化”表达空间。目标是：在保留 NTC 初态所决定的真实效应异质性的前提下，消除跨公开数据拼接造成的不可比性，并为共享 GRN-ODE 提供可审计的 KD 因果证据。

同一 KD 在不同细胞系出现的价值是观察 `tau_a(S)` 在多个初态上的条件效应，并检验其中是否存在可共享的机制；不是把这些响应简单平均成一个与状态无关的 delta。

## 1. 变量、图与识别目标

令一个实验环境为 `e=(study, cell line, protocol, batch, replicate, time)`：

```text
S_e: matched NTC 推断的细胞系初始状态（可观测、预干预）
H_pre: 可观测的预处理/设计变量（study、协议、批次、guide system、时间等）
A_e: 本环境实际测到的 KD gene；0 表示 matched NTC
Z_ea: 实验内分配到 target/guide a 的处理指示
K_ea: 实际敲低强度；只有被可靠测量或识别时才用于剂量效应
Y_e^a: KD a 后的单细胞表达分布
Q_ea^post: KD 后 QC、cell cycle、stress、凋亡等潜在中介或选择相关变量
V_ea: 存活、捕获并通过观测/QC 的选择指示
U_e: 未记录的批次/实验偏差
```

实验内问题与跨资料库问题必须分开。实验内由 `Z -> K -> Y` 表示 target/guide 分配、实际敲低和响应；`S` 可影响 `K/Y/V`，`Y/K` 也可能影响选择 `V`。跨资料库拼接时，`S,H^pre -> A_obs` 表示某个 KD 是否恰好在某种细胞系/协议中被测到；`S,H^pre,U -> Y`。实验内近似随机的分配可以支持 target-assignment 相对 NTC 的效应，但不能自动识别每单位实际敲低效应、消除存活选择或证明直接 gene-to-gene 调控；跨资料库的覆盖选择则决定效应能否运输。

目标是条件因果响应而非一个错误的全局平均：

\[
tau_a(S)=\mathbb E\{Y^a-Y^0\mid S\}.
\]

`S` 是效应修饰变量。只有技术偏差和数据覆盖不均衡需要校正；若 KD 在不同初态下确有不同生物学响应，这一差异必须传给 ODE，而不是被 batch correction 删除。

### 1.1 四层 estimand

项目使用四个不可互换的 estimand：

| ID | 对象 | 主要用途 | 关键边界 |
| --- | --- | --- | --- |
| `E1_assignment_itt` | 同环境 target/guide assignment 相对 NTC 的终点分布效应 | 默认实验内证据 | 包含由 target assignment 引起的总效应；受分配质量、脱靶、干扰和选择影响 |
| `E2_knockdown_dose` | 实际靶基因敲低一个单位对下游响应的效应 | soft-intervention 强度 `rho` 的可选校准 | 需要可靠 `K`、多 guide/强 first stage 和排除限制；不能由 E1 自动推出 |
| `E3_transport` | 在预先定义的目标 NTC 状态分布中，外部 E1/E2 是否可运输 | 共享证据与 OOD 解释 | 需要共同支持、设计变量可比性和运输假设 |
| `E4_prediction_distribution` | 给定目标 NTC 与 target 后生成的比赛 raw-count 分布 | 最终预测与提交 | 可在 E2/E3 不可识别时由冻结 fallback 产生；预测成功不升级因果结论 |

S02 在计算证据前冻结实验内 DAG、运输 DAG、estimand ID、统计单位、目标总体、允许协变量和选择/干扰假设。任何下游输出必须引用其中一个 estimand；不能把 `d_ea`、`tau_a(S)`、ODE 输出和最终 400-cell 分布写成同一对象。

## 2. 进入 GRN-ODE 前的证据前端

### 2.1 同环境 NTC 差分是第一步

先从 NTC-only 细胞拟合跨数据集可解释的 program 表示 `psi`，且在每一个外层训练折中重新拟合。对每个 KD 环境，保存原始分布及其 program 条件差分：

\[
d_{e,a}=\mathbb E[\psi(Y_{e,a})]-\mathbb E[\psi(Y_{e,0})].
\]

若

\[
Y_{e,a}=m(S_e)+b_e+tau_a(S_e)+kappa_{e,a}+epsilon_{e,a},
\]

则 matched NTC 差分消去细胞系基线 `m(S_e)` 与对 KD/NTC 共同的加性批次项 `b_e`，保留 `tau_a(S_e)+kappa_{e,a}`。这不是同一细胞的 before/after，因此不制造细胞级配对或轨迹。

### 2.2 用状态分层与共同支持域处理数据覆盖

对每一个 KD `a`，先在 NTC program 状态 `S` 与实验时间上建立粗粒度 strata 或局部邻域。仅保留既有 NTC 对照、又与同 KD 的其他环境具有可比状态支持的记录；对没有重叠的区域标记为不可运输，而不是用模型外推后当作证据。在每个状态 strata 内，再对可观测技术协变量 `H` 作平衡或校正。

高维 `S` 不适合直接按每个基因分层。首版使用少量、预先定义的 NTC gene-program 分数和技术元数据作平衡变量，随后报告每个 KD 的标准化差异、核 MMD、有效样本量和权重范围。平衡的目标是建立可比训练证据，不是把倾向模型的分类准确率做高。

还必须审计数据的交叉连接性：同一 KD 应跨多个初态出现；同一初态或可比状态域应在多个 batch/protocol 有重复，或有一组 bridge KD 横跨这些 batch。若 `cell line` 与 `batch` 永远一一对应，二者完全共线，观察到的差异无法拆分为状态效应和批次效应。此时只可把该数据视为单域证据，不能靠 propensity score、DID 或神经网络补出识别性。

### 2.3 先做层级效应汇总，再按条件启用平衡权重

默认共享效应分析使用 condition/replicate 级的低维分层模型或 meta-regression：KD 的共享项表示平均可迁移成分，`S` 及其预注册交互表示状态依赖，study/protocol/batch 只在存在交叉重复时作为技术随机项或固定项。必须报告环境间异质性、预测区间、leave-one-environment-out 行为和单环境影响度；环境数少时限制 moderator 数量并使用收缩/小样本不确定度，不能把大细胞数当作更多独立环境。

只有独立环境数、交叉重复和共同支持足够时，才对 `A_obs=a` 的覆盖选择估计密度比/广义倾向评分：以 `S` 的共同支持作为可运输范围，在状态 strata 内使用熵平衡、核平衡或稳定近似平衡权重处理允许的 `H^pre`。只有在需要把不同状态的边证据汇总时，才按预先定义的 `S` target 作标准化；ODE 的主训练始终保留 `(S_e,d_{e,a})` 条件对。权重记为 `w_{e,a}`，并截断极端权重；严重缺乏共同支持时直接放弃该 KD 在共享证据中的权重。

这不是把单细胞当成独立随机接受处理的个体，也不应对每个细胞盲目作 IPW。加权单位是“有 matched NTC 的 KD 条件/重复”，单细胞用于估计该条件的均值、分布与抽样方差。

### 2.4 双重稳健用于效应摘要，不伪造万能校正矩阵

对于 program、候选边或其他低维效应摘要，在独立环境数足够时可交叉拟合两个 nuisance 模型：条件效应回归 `m_a(S,H^pre)` 和 KD 覆盖模型 `pi_a(S,H^pre)`，再用 augmented/IPW 的双重稳健估计生成效应值及方差。其保证仍依赖 positivity、至少一个 nuisance 模型充分正确以及未观测偏差条件；样本量不足或无法交叉拟合时必须 `not_run`。

该步骤输出的是带不确定度的证据表，而非覆盖原始矩阵的单一“corrected expression”。GRN-ODE 仍见到原始匹配分布，但其跨环境损失按 `w` 加权，并按效应方差降权。

### 2.5 候选边与 program 效应的异质性和敏感性门控

S02 默认层级汇总与模型训练后的边级复核使用同一 estimand 语义。对候选边/程序效应输出共享项、状态依赖、技术方差、环境异质性、预测区间和敏感性区间，而不是将批次残差直接从所有预测中扣除。跨环境稳定不能由“不显著异质”单独判定；需要预注册 practical-equivalence 界值、预测区间和最小环境覆盖，探索性多边检验还需控制多重比较。

最终预测只使用目标细胞系 NTC 估计的 `S_target` 和训练期冻结的共享机制。若某条边或某个 KD 的符号在合理未观测偏差范围内不稳定，则将其从共享图剔除或降低权重；这属于后处理的证据门控，不是事后利用比赛隐藏标签调参。

### 2.6 协变量角色与禁止调整项

每个字段必须在 S00 registry 中登记 `measurement_timing` 和 `covariate_role`。允许进入匹配、分层、覆盖模型或技术项的变量仅限预处理状态、实验设计变量和预注册 effect modifier。KD 后 library size、检测基因数、线粒体比例、cell cycle、stress/IFN、凋亡、重标注 cell type、存活/捕获等可能是中介、选择变量或诊断量，不能作为普通混杂变量回归掉。它们只用于 QC 决策、选择偏差/截断敏感性分析或明确的中介问题；未知时间顺序时默认不进入调整集。

不同细胞可能通过 pooled-culture/paracrine 等机制相互影响。若数据不能支持 no-interference，报告实验单位、池化范围和可允许的 partial-interference 假设；不得把单细胞数量解释为独立随机化单位。

## 3. DID、批次与不可识别的部分

matched NTC 差分是有对照的条件比较，不是经典 DID：本任务通常只有终点表达，没有同一单位的多个预处理时点，因此不能默认满足平行趋势。

当同一 `cell line x KD` 在多个批次/协议有独立重复时，可以比较

\[
d_{c,b,a}-d_{c,b',a}.
\]

它检验已经做过 NTC 差分后是否仍存在 `KD x batch` 交互。若有多个共同 KD 和可比重复，可用 DID/三重差分或含 batch 随机效应的分层模型估计该交互，并把不确定度传入训练权重。DID 的前提仍是未观测偏差的作用在相关比较中可分离且稳定；没有重复或负对照时无法检验这一点。

因此分三类处理：

| 情形 | 可做的处理 | 不可宣称 |
| --- | --- | --- |
| 同环境 matched NTC | 条件差分消去共同加性偏差 | 已消去 KD 特异的批次效应 |
| 同一 KD 有跨批次/跨协议重复 | 分层随机效应、DID/三重差分诊断、方差膨胀或剔除不稳定 KD | 任意未观测交互均已识别 |
| 无重复且无有效代理 | 保留为高不确定度或不用作共享证据 | 从表达终点“算法性去混杂” |

NTC guide 只提供对照处理，不能单独充当识别任意未观测混杂的代理变量。若数据中另有满足负对照暴露和负对照结局条件的技术代理，才可以评估 proximal causal learning；若没有，不能把该方法写成默认方案。

guide 身份作为工具变量只服务 `E2_knockdown_dose` 或 `rho` 校准，不替代 E1。启用前必须有多条近似随机分配的独立 guide、可测且强的 first stage、可辩护的排除限制/单调性、脱靶和载体应激审计，以及存活选择诊断；不满足时保持 `not_identifiable`。候选图或表达数据本身不能循环地定义“保证不受 target 影响”的负对照结局。

## 4. 与 GRN-ODE 的接口

训练前端产出每个 `(e,a)` 的：

```text
raw NTC / KD distributions
NTC-derived initial-state summary S_e
matched program effect d_ea and bootstrap variance
technical metadata H_pre
estimand_id and target population
covariate-role manifest and allowed adjustment set
overlap stratum, balancing weight, support flag
batch-interaction diagnostic and sensitivity label
selection/interference flags and measurement timing
rho source/calibration status when E2 is attempted
```

ODE 的任务是用 `z(0)=S_e` 和 soft intervention `u_a` 解释这些加权条件效应。共享图的候选边还应在多个环境中通过不变性检验；这服务于“哪条耦合在不同环境下稳定”，不替代前端的可比性校正。

## 5. 必须通过的审计与失败门槛

- 每个进入共享图学习的 KD 都必须有 matched NTC、可追溯时间与 batch/replicate 元数据；
- 在加权后检查每个 `S,H` 的平衡、极端权重和有效样本量；共同支持不足的 KD 只可作单域辅助数据；
- 用 duplicate guide、技术重复和已知无效/阴性 perturbation 做 placebo；
- 对批次交互做敏感性分析：在合理的未观测偏差范围内，边符号和 LOCO 排名是否稳定；
- 检查任何用于 adjustment 的字段都属于允许的预处理/设计角色，post-treatment/selection 字段不会进入默认调整集；
- 对多时间点证据只在设计、剂量和协议可比时报告 temporal support；跨 study 的最早出现时间不能单独升级为直接调控边；
- 不使用 scVI、Harmony、MNN 等对 KD 与 NTC 的所有细胞作无约束整合来生成训练标签；这些工具最多在 NTC-only 技术校准中评估，且必须证明不抹除细胞系初态或 KD 信号。

## 6. 方法选择

| 方法 | 在本项目中的位置 | 关键假设/边界 |
| --- | --- | --- |
| matched NTC assignment effect + condition uncertainty | 默认前端 E1 | NTC 与 KD 环境匹配；分配/脱靶/选择/干扰边界显式；只消去共同加性偏差 |
| 分层随机效应 / meta-regression | 默认跨环境汇总与强基线 | 独立单位是环境/重复；moderator 数受环境数限制；报告异质性与预测区间 |
| 熵平衡、核平衡、稳定平衡权重 | 有足够环境和 positivity 时建立 E3 目标总体 | 只能平衡观测到的 `S,H^pre`；需 ESS、影响度和权重诊断 |
| 双重稳健 / DML / CATE | 条件触发的低维 E3 摘要 | 可观测混杂充分、可交叉拟合；不处理未测批次交互 |
| DID / 三重差分 | 有重复批次时诊断残余批次交互 | 平行趋势或可分离稳定偏差；终点数据不能默认满足 |
| guide-IV | 可选 E2/`rho` 校准 | 强 first stage、排除限制、单调性、脱靶和选择假设；不是默认运输方法 |
| ICP / Joint Causal Inference | 可选共享候选边/程序筛选 | 机制不变、环境/干预假设成立；不能用不拒绝零假设证明不变 |
| BackShift / Causal Dantzig 类方法 | 低维线性化 program 图的辅助筛选 | shift-intervention、隐藏混杂稳定等强假设；不替代 nonlinear ODE |
| proximal causal learning | 仅在找到有效双代理后探索 | 代理变量需满足 confounding-bridge 条件，NTC 本身通常不足够 |
